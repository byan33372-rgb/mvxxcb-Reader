## 0. 依据与口径声明

1. **§22 全链路口径**：产品简报原文未入库；本单以主 Agent 整合日志 docs/05（阶段 6 记录）引用的 §22 范围为准：**导入 → 详情 → 目录 → 阅读 → 排版变更 → 进度恢复 → 断网读缓存**，并叠加 docs/01 §10 一期范围与回归清单 36 条（REG-E2E 2 + REG-READER 10 + REG-MAP 21 + REG-PERF 3）。若产品简报 §22 原文与本单有出入，**以原文为准**并由 WP-Q 回填本单。
2. **验收站点（执行输入，非虚构）**：步骤中 `<验收站点URL>` 为占位——须由主 Agent 提供 ≥1 个**公网可达**的小说站（详情页/目录页/章节页可解析）。**禁止**使用本机 mock 地址（`10.0.2.2`、`127.0.0.1`、私网 IP）：应用安全层按设计拦截私网/回环地址（v1.0.3 §13.1.5 生产装配无测试后门），私网地址必被 Blocked——该拦截行为本身作为异常路径用例（L3），不作为正常链路的站点来源。
3. **条件步骤标注**：凡依赖站点形态的步骤标 **[站点相关]**——站点不具备该形态时，状态记"环境受限（未执行）"并在记录注明，不算执行失败；缺陷回路由主 Agent 裁定。
