## 5. WP-S · security（安全）

**依赖契约条目**：§3（Security 错误/BlockedReason）、§4（全部）、§10（Security 行）。

**负责文件清单**

```
src/security/UrlSecurityValidatorImpl.kt         （IP 解析级校验：回环/私网/链路本地/保留段/元数据端点/IPv6 变体）
src/security/SecureHttpClientImpl.kt             （唯一 OkHttpClient；重定向逐跳复查；大小/重定向/超时/同主机限流；协程取消桥接 call.cancel()）
src/security/ContentSanitizerImpl.kt             （script/style/iframe/事件属性/危险协议剥离）
src/security/NetworkLimits.kt                    （签名由 WP-M 生成，默认值策略在此）
src/security/DnsPinningResolver.kt               （DNS 解析结果校验钩子，防 DNS rebinding——实现可选，缺省则逐跳复查兜底）
test/security/**/*.kt                            （SSRF/限额/净化单测）
docs/security/审查报告-安全基线.md                （TLS 策略、WebView 预留接口的安全要求、隐私最小化清单）
```

**DoD**
1. SSRF 单测全绿：`localhost/127.0.0.1/0.0.0.0/10.x/172.16-31.x/192.168.x/169.254.x/100.64.x/::1/fc00::/fe80::/十进制与十六进制 IP 变体/云元数据 169.254.169.254` 全部 Blocked；`http(s)` 之外 scheme Blocked。
2. 重定向到私网地址被拦截（REDIRECT 类 reason）；重定向计数超限报错；响应体超 8MB 中断（RESPONSE_TOO_LARGE）。
3. `fetch` 全部失败路径返回 `AppResult.Failure(ReaderError)`，不抛异常跨层。
4. 净化输出不含 script/style/iframe/on* 属性/javascript: 协议。
5. 输出《安全基线》含 WebView 二期启用前的强制要求清单（隔离进程/禁文件访问/白名单域名/禁 JSI 泄漏）。

**顺序**：P1 起并行；P1 首日先交付 §4 接口文件核对（parser 编译依赖）+ 首版 Validator。
