- 用户要求：把 README「Flutter 版已知限制（v1）」四项全部移植——①站点规则可视化编辑器 ②WorkManager 后台隔离 ③诊断反馈 ④自适应限速（＋Baseline Profile 补充）。

- **②WorkManager 后台隔离**：`workmanager ^0.10.10`（Android 端 zero-config，`gradle.properties` 启用 dataSync 前台服务类型）；执行内核抽至 `impl/crawl_task_runner.dart`（前台队列与后台隔离共用）；`crawl_tasks` 新增 `lease_until` 租约列——双入口 DB 抢占互斥防双跑，每章续租（TTL 2min）；`downloadWholeBook/resume/retryFailed/restoreOnStartup` 追加挂后台 Work（keep 幂等），`pause/cancel` 撤销；iOS 未接入（README 如实声明）。
- **③诊断反馈**：`impl/diagnostics_impl.dart` 对齐 Kotlin 文本口径（设备与应用/数据库统计/采集任务≤10条/阅读设置/最近操作日志 120 行/生成时间），URL 一律 redactUrl 脱敏、TXT 只出文件名；`core/app_log.dart` 环形日志（release 不落 logcat）；UI 经 `share_plus 12.x`（`SharePlus.instance.share(ShareParams)` 新 API）系统分享导出。
