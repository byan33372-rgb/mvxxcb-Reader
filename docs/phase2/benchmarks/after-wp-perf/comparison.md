## 书架场景诚实分析
1. 优化项（稳定 key/contentType/分组记忆化/角标读取上提）逻辑正确且有单测，但模拟器下**封面夹具为空**（Coil 解码尺寸修复无从体现），瓶颈为 swiftshader 软渲染整屏重绘——真机 GPU 下封面解码收益预计显著，**需真机复测**。
2. 软渲染下 P95≈43ms 属环境固有（整屏 CPU 光栅化），真机 GPU 合成路径完全不同。
3. 复跑×2 数据稳定（P50 27.3/29.7，P95 43.0/46.1），非偶发。

## 结论
- 目录长尾、阅读器帧生成：模拟器口径下已实证改善。
- 书架：改动保留（正确性可证 + 真机预期收益），模拟器无法证明，列入真机验证清单。
- 后续：M1 视觉升级、Baseline Profile 生成（插件已就绪）、真机 60/120Hz 对照（需用户 Pixel 真机）。
