## 5. 关键裁定与偏差记录（全部经主 Agent 批准）

1. **去重键归一**：BookResolver 回溯导入的 sourceUrl 统一取定位详情页 URL（验收实测：章节 URL 导入曾产生重复书）。
2. **回溯标题保护**：命中已有书时置空解析标题，防"卷/章节"尾巴污染（实测缺陷修复）。
3. **域间隔 500ms→2s**：linovelib 实测 500ms 突发在 4-5 请求后触发站点限制；收紧后单次采集 19/19（合规姿态，契约 v1.1 追加）。
4. **TXT 原子写 + SHA-256**：本轮补齐（§7 明示要求；契约 v1.1.1 增量字段 fileSha256）。
5. **Worker 自动登记 LocalBook**：满足"TXT 自动进入本地书架"（07 设计为手动导出登记，实测补齐为自动）。
6. **K10 采集门面**：ReadingService 七方法（可空参数保持一期构造兼容）。
7. **WP-M0 文件名/枚举名与 07 的字面差异**：按 M0 实际落盘为准（CrawlModels.kt/CrawlState/AppMigrations.kt），功能等价。
