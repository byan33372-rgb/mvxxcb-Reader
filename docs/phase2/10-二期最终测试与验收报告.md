## 3. 测试边界声明（总指令 §15/§17.8）

1. **真实站点测试**：linovelib.com 端到端实测（导入/回溯/采集/TXT/离线）为**当次真实结果**；站点结构随时可能变化，不构成对任意网站持续兼容的承诺；自动回归一律使用本地 fixtures（19+6 个 HTML 样本）。
2. **connected（仪器）测试未执行**：androidTest 为编译骨架；模拟器交互验收以 adb+uiautomator 手动驱动替代（D22 延后）。
3. **横屏/平板**：布局自适应代码就绪（widthIn 600dp），但仅在竖屏模拟器实测；横屏截图缺失，如需正式验收建议真机补充。
4. **真实站限流**：实测站点存在突发频率限制（~4-5 请求突发后阻塞数分钟）；已将域名间隔收紧为 2s 并验证单次采集 19/19；极端站点可能需多次"重试失败章"分批完成。
5. **未执行项**：D22 connected；故障注入框架未立项（按 08 文档决策）。

## 4. 安全测试

- SSRF 全矩阵 17 例（含十进制/十六进制 IP 变体/IPv6 ULA/云元数据端点）+ 重定向逐跳复查 21 例 + 净化 14 例 + DNS 5 例，**57/57 全绿**。
- 真机拦截实测：`http://127.0.0.1:1/` → 安全横幅（T14 附带验证）。
- 合规机制：域名最小间隔 2s、全局串行单任务、403/401/验证码页 → 失败记录不重试不绕过、只采集用户明确选择的一本书。
- 本轮新增安全审查点：TXT 原子写（防伪完整文件残留）+ SHA-256 完整性哈希；Coil 直连收口为 P1（见 08 D18）。
