## 2. 安装步骤

1. 将 `简阅-2.0.0-debug.apk` 传输到 Android 手机（或 `adb install -r 简阅-2.0.0-debug.apk`）。
2. 允许"安装未知应用"（debug 签名非商店包）。
3. **从 MVP 0.1.0 升级安装**：直接覆盖安装，v1→v2 数据库迁移自动执行（书架/进度/规则零丢失，已实测）。
4. 首次启动后底部三 Tab：书架 / 发现·导入 / 我的（内含 阅读设置 / 规则管理 / **采集中心**）。

## 3. 新增功能使用流程（核心闭环）

1. 复制任意受支持小说站的**详情页、目录页或任意章节**网址（含中间章/末章）。
2. 发现·导入 → 粘贴 → 开始解析：应用自动识别页型；章节页会**反向回溯所属小说与完整目录**（低置信度或找不到目录时，按提示补充目录页网址）。
3. 确认书籍信息进入详情页 → 点【下载整本小说】→ 开始下载。
4. 采集中心（我的 → 采集中心）实时查看：总章/成功/失败/当前章/状态；支持暂停、继续、取消、重试失败章、清除记录。
5. 采集完成自动生成 **TXT**（应用私有目录 `filesDir/txt/<bookId>/`，含 SHA-256 完整性哈希）并**自动进入书架**（「已下载」分组）。
6. 书架点开即读：默认**连续滚动模式**——读完一章自动衔接下一章，无需点击；设置面板可切换 滚动/翻页/连续。
7. 退出后重开自动恢复到上次位置（精确到章节内字符偏移）；断网可读全部已采集内容。
8. 详情页「导出 TXT」可将文件另存到手机任意目录（SAF）。

## 5. 已实现 / 部分实现 / 未实现（总指令 §17.8 五分法）

- **已实现并通过测试**：BookResolver 反向识别、完整目录（分页/去重/排序/分卷）、全本采集引擎（六态/断点续传/暂停恢复/单章重试/进程恢复）、TXT 生成（原子写/SHA-256/完整性校验/失败清单）、LocalBook 书架整合（五分组/无重复书）、跨章节连续阅读（charOffset 主锚点/窗口 LRU）、Pixel 全面屏适配、SSRF/限速合规、v1→v2 迁移、328 单元/集成用例、15 项场景验收。
- **已实现但测试受限**：横屏/平板布局（代码就绪，仅竖屏实测）；connected 仪器测试（未执行，D22）。
- **部分实现**：正文文件化（v2 列预建未启用，D15）；书签精确定位（charOffset 统一，书签仍到章首，D10 剩余）；封面本地 URI（D18 收口 P1）。
- **因网站限制无法保证**：任意站点 100% 自动解析（失败给明确原因+人工规则兜底）；反爬严苛站点需分批重试。
- **未实现（延后，见 08 文档）**：WebView 动态页、RuleTester、自定义字体、EPUB 导入、翻页动画、手势扩展、规则自动学习、备份联动。

## 6. 数据与隐私

- 全部数据仅存本地（Room v2 + DataStore + filesDir）；不上传书架/进度/网址。
- 采集仅限用户明确选择的一本书；域名最小间隔 2s；不绕过任何访问控制。
- 卸载应用即删除全部本地数据（含 TXT）。

## 7. 后续建议（三期候选）

1. 书签精确定位补齐 charOffset（D10 剩余）＋独立书签页。
2. 正文文件化激活（D15 列已预建）＋备份联动（D16）。
3. RuleTester 规则在线测试（D3）＋自定义字体（D8）。
4. WebView 受控辅助解析（D2，六前置达标后）。
5. 本地 TXT 文件导入入口（独立导入路线）＋ EPUB（D14）。
